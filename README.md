# מערכת צירים — הרביע הראשון

אתר וחוברת ללימוד מערכת הצירים ברביע הראשון: **78 עמודים ממוספרים להדפסה**, שער, תוכן עניינים, ספר דיגיטלי, מובייל והדפסת A4.

**מקור האמת היחיד של הפרויקט:** `USER_MEMORY.md`.

## מצב נוכחי

- הספר הדיגיטלי הוא האתר עצמו — הכניסה הרגילה נפתחת מיד על הכריכה.
- 78 עמודים ממוספרים; שער + תוכן עניינים = **80 גיליונות בחוברת המלאה**.
- כל משימה ממוספרת פתירה על נייר; אין שעשועונים מקוונים בתוך העמודים הממוספרים.
- דפי חידה/פענוח קיימים כדפי עבודה מודפסים.
- פעולות סרטון, פתיח, תשובות, המחשות, הורדה, הדפסה, קריאה נגישה ושיתוף זמינות מתוך הספר.
- `#/print-aids` מכיל המחשות A4 נפרדות ואינו חלק ממספור החוברת.
- האתר הרשמי, שאינו משתנה: `https://yanivmizrachiy.github.io/coordinate-first-quadrant/`.

## נתיבים

- `#/` — הספר הדיגיטלי הקנוני.
- `#/book`, `#/menu`, `#/workbook`, `#/games` — קישורי תאימות שמגיעים לאותו ספר.
- `#/workbook/:n` — עמוד בודד/קריאה נגישה.
- `#/print` — החוברת הרציפה ב־A4, מקור ההדפסה וה־PDF.
- `#/solutions` — מקור פנימי לבניית חוברת התשובות.
- `#/print-aids` — המחשות להדפסה.

## פיתוח ובדיקות

```bash
npm install
npm run dev
npm run verify
```

`npm run verify` הוא שער הסיום: typecheck, בדיקות יחידה/תוכן, build ובדיקות דפדפן/רינדור.

אחרי שינוי שנראה **בעמודי A4 עצמם**:

```bash
npm run pdf
```

יש לוודא שהחוברת נשארת **80 עמודי PDF**, ללא עמודים ריקים וללא גלישה, וש־`hoveret-map.json` תואם. שינוי במעטפת הקורא בלבד אינו מחייב יצירת PDF חדש.

## פרסום

GitHub Pages הוא הקישור הציבורי הרשמי. אחרי merge ל־`main`, workflow הפרסום מריץ מחדש את שערי האימות ומפרסם לאותה כתובת. `workflow_dispatch` נשאר גם להפעלה ידנית/שחזור.
